# Kaggle_Titanic
## Overview
### 背景
RMS タイタニック号の沈没は、歴史上最も有名な海難事故の一つです。1912年4月15日、処女航海の最中に氷山と衝突して沈没し、2224人の乗客・乗組員のうち1502人が死亡しました。これほどの犠牲者を出した理由の一つは、乗員・乗客全員分の救命ボートが用意されていなかったことです。
生存には運の要素もありましたが、女性、子供、上流階級の人々など、一部のグループは他の人々より生存しやすかったと考えられています。
### 課題(Task)
このコンペでは、乗客データ(氏名、年齢、性別、社会経済的階級など)をもとに、どのような人々が生存しやすかったのかを予測するモデルを構築することが課題です。テストセットの各乗客について、生存(1)か死亡(0)かを予測します。
### 評価指標
スコアは、正しく予測できた乗客の割合であり、正解率(Accuracy)と呼ばれます。
### データファイルの説明
コンペのDataタブには、3つのファイルが用意されています。
1. **`train.csv`(訓練データ、891件)**
   モデルを学習させるためのデータです。乗客の特徴量(氏名、性別、年齢など)に加えて、実際に生存したかどうかの正解ラベル(`Survived`)が含まれています。
2. **`test.csv`(テストデータ、418件)**
   モデルの性能を試すためのデータです。`train.csv`と同じ種類の特徴量が含まれていますが、`Survived`列(正解)は含まれていません。これを予測するのが課題です。
3. **`gender_submission.csv`(提出サンプルファイル)**
  「女性のみが生存する」という単純な仮定に基づいた予測例として提供されているファイルで、提出ファイルがどのような形式であるべきかを示す見本です。女性を優先的に救命ボートに乗せたという歴史的背景から、この単純なルールだけでも一定の精度(約0.76前後)が出ます。
### データ辞書(主な列の説明)
| 列名 | 説明 |
|---|---|
| PassengerId | Kaggleが付与した通し番号(識別用) |
| Survived | 生存したか(0=死亡, 1=生存)。予測対象 |
| Pclass | チケットの等級(社会経済的地位の代理指標。1=上流, 2=中流, 3=下流) |
| Name | 氏名 |
| Sex | 性別(male/female) |
| Age | 年齢(1歳未満は小数、推定年齢はxx.5の形式で表される) |
| SibSp | 同乗する兄弟姉妹・配偶者の人数 |
| Parch | 同乗する親・子供の人数 |
| Ticket | チケット番号 |
| Fare | 運賃 |
| Cabin | 客室番号 |
| Embarked | 乗船港(C=Cherbourg, Q=Queenstown, S=Southampton) |

### 提出形式
PassengerIdとSurvivedの2列だけを持つCSVファイルを提出する必要があり、正確に418件のエントリ(ヘッダー行を含む)が必要です。それ以外の余分な列や行数の過不足があるとエラーになります。
